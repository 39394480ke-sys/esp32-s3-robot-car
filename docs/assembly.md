# 机械装配与布线

本文记录当前实物的装配基线。所有形状、孔位和零件相对位置应以 [STEP 装配](../mechanical/cad/esp32-s3-robot-car.step) 为准。

![整车侧后外形](../assets/photos/car-side.jpeg)

## 结构组成

- 双轮 TT 电机底盘和底部支撑结构
- 圆角上盖与左右轮避让开口
- 顶部双轴 SG90 云台
- 云台显示器外壳及摄像/传感部件安装区域
- 侧面扬声器孔、开关和接口开口
- 底盘内部电子模块安装空间

现有资料没有给出打印材料、层高、壁厚、填充率、支撑策略、螺钉规格或尺寸工程图，不应根据照片推断这些制造参数。

## 内部布局基线

![底盘内部原型接线](../assets/photos/interior-wiring.jpeg)

| 区域 | 建议安装对象 | 目的 |
|---|---|---|
| 底部或后部 | 12V 电源、两个 LM2596、TB6612 | 降低重心，缩短大电流路径并便于散热 |
| 中部 | ESP32-S3、面包板或转接板 | 保留 USB 和调试接口的可达性 |
| 前部/上层 | TOF、OV3660、OLED、双轴云台 | 保证视野、测距方向和显示可读性 |
| 侧面开口 | 船型开关、扬声器 | 对齐 STEP 中对应开孔并避免压线 |
| 远离噪声处 | INMP441 | 减少电机、降压模块和扬声器干扰 |

照片中的面包板和散开的杜邦线属于调试状态。重新开发时应优先改为有锁连接器、定长线束和可靠的应力释放，不要让松散线束接触轮胎、舵机或外壳边缘。

## 推荐装配顺序

1. 在 CAD 中确认底盘、上盖、云台支撑、显示器外壳和开关等零件齐全，导入单位保持毫米。
2. 安装左右 TT 电机与轮组，确认两侧轮胎自由转动且不会摩擦外壳开口。
3. 固定电池、LM2596 和 TB6612，保留 LM2596 调压位置并缩短电池至驱动板的线长。
4. 固定 ESP32-S3 与转接板，使 USB 口、开关和必要的维护接口在合壳后仍可接近。
5. 在安装舵机摇臂前，用舵机测试器或等效方法使两个 SG90 位于机械中位，再分别装入 Yaw/Pitch 结构。
6. 安装 OLED、OV3660、TOF、扬声器和麦克风，检查视野、声孔和外壳开孔没有遮挡。
7. 按电源、执行器、传感器、摄像头四类整理线束，完成后再安装上盖。
8. 合壳前进行连续性、电压、温升、轮组和云台干涉检查。

## 线束分区

| 线束类别 | 包含线路 | 布线要求 |
|---|---|---|
| 主电源 | 12V、6V、5V 和公共地 | 线径与电流匹配，极性清楚，接头固定 |
| 电机动力 | TB6612 到左右 `M+/M-` | 尽量短，可轻绞，远离传感器线 |
| 编码器与传感器 | H1/H2、I2C、I2S | 与电机动力线分开，避免悬空和拉扯 |
| 云台 | 5V、GND、Yaw、Pitch | 在穿出上盖处做应力释放并保留运动余量 |
| 摄像头 | OV3660 FPC | 保持自然弯曲半径，不折死角、不被壳体夹住 |

面包板可按左侧 3V3 逻辑/传感器区、右侧 5V 执行器区分配；左右只桥接 GND，不连接 3V3 与 5V。6V 电机电源不建议长期经过面包板弹片。

## 合壳检查

- 轮胎与外壳保持间隙，手动转动没有卡滞。
- 云台在允许行程内不会撞壳、拉扯线束或压住摄像头排线。
- TOF 和摄像头前方没有外壳边缘、线束或紧固件遮挡。
- 扬声器与侧面声孔对齐，线束不接触振膜。
- USB、开关及维护连接器可以操作。
- 所有电路板和接头固定，晃动车体时不会移动或松脱。
- 上盖闭合后没有夹线，底盘内没有裸露的 12V 导体。
